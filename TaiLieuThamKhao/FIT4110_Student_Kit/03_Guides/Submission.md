# Submission

## Submit one portfolio URL

Use one public repository, `FIT4110_<MãSinhViên>`, for the entire semester. Each lab belongs in its matching top-level folder. Do not submit a local folder, a temporary link, or a different repository for each lab.

## Before each deadline

1. Run the current lab's verification commands from a clean terminal.
2. Complete its checklist and `known-issues.md`.
3. Confirm no secret or local-only file is tracked with `git status` and `git ls-files`.
4. If the lab contains shared team work, confirm its artefacts match the agreed version and complete that lab's `CONTRIBUTION.md`.
5. Push the latest commit to your public portfolio repository.
6. Confirm the current lab is in its required folder and earlier labs remain intact.
7. Submit the same portfolio URL through the course submission channel.

The submitted URL identifies the whole semester portfolio. Keep reports, screenshots, run instructions, and corrections in the relevant lab folder. Do not rewrite history after a lab deadline; make a new commit and document any correction.

# Nộp bài

## Nộp một URL portfolio

Dùng một repository public, `FIT4110_<MãSinhViên>`, cho toàn bộ học kỳ. Mỗi Lab nằm trong thư mục top-level tương ứng. Không nộp thư mục local, link tạm thời hoặc repository riêng cho từng Lab.

## Trước mỗi hạn nộp

1. Chạy các lệnh kiểm tra của Lab hiện tại từ một terminal sạch.
2. Hoàn thành checklist và `known-issues.md` của Lab.
3. Xác nhận không có secret hoặc file chỉ dùng local được track bằng `git status` và `git ls-files`.
4. Nếu Lab có công việc chung của nhóm, xác nhận artefact đúng với bản đã thống nhất và hoàn thành `CONTRIBUTION.md` của Lab đó.
5. Push commit mới nhất lên repository portfolio public.
6. Xác nhận Lab hiện tại nằm đúng thư mục và các Lab trước còn nguyên.
7. Nộp cùng một URL portfolio theo kênh nộp bài của học phần.

URL đã nộp đại diện cho toàn bộ portfolio học kỳ. Lưu report, ảnh chụp, hướng dẫn chạy và mọi sửa đổi trong thư mục Lab liên quan. Không rewrite lịch sử sau mốc nộp Lab; tạo commit mới và ghi rõ mọi sửa đổi.
