# Lab 01 — Setup and evidence

**Purpose:** prepare the workstation, verify the toolchain, generate environment evidence, and define the first service boundary.

Create and clone your `FIT4110_<MãSinhViên>` portfolio before beginning this lab. Use [FIT4110_setup](https://github.com/TrangLe1912/FIT4110_setup) as the authoritative technical guide. Copy the starter contents without `.git` into `01_Setup/`, then run the supplied `pull_all`, `smoke_test`, and `collect_session01_evidence` scripts from `01_Setup/`; this makes `git-log.txt` reflect your own portfolio history. The source repository does not provide a separate setup script. Complete every file listed in its `evidence/buoi-01/` checklist.

Use this Kit's [single-repository workflow](../03_Guides/Submission.md) for the portfolio and submission steps.

# Lab 01 — Thiết lập môi trường và minh chứng

**Mục đích:** chuẩn bị máy học tập, kiểm tra toolchain, sinh minh chứng môi trường và xác định service boundary đầu tiên.

Tạo và clone portfolio `FIT4110_<MãSinhViên>` trước khi bắt đầu Lab này. Dùng [FIT4110_setup](https://github.com/TrangLe1912/FIT4110_setup) làm hướng dẫn kỹ thuật chính thức. Sao chép nội dung starter không kèm `.git` vào `01_Setup/`, sau đó chạy các script `pull_all`, `smoke_test` và `collect_session01_evidence` từ `01_Setup/`; khi đó `git-log.txt` sẽ phản ánh lịch sử portfolio của chính sinh viên. Repo gốc không có script cài đặt riêng. Hoàn thành đầy đủ các file được liệt kê trong checklist `evidence/buoi-01/` của repo gốc.

Dùng [quy trình một repository duy nhất](../03_Guides/Submission.md) của Student Kit cho các bước portfolio và nộp bài.
